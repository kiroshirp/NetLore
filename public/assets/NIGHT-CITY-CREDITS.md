# Night City cartography

The street image is a top-down projection of Cyberpunk 2077 game map geometry, obtained from the map supplied as the design reference:
https://atlasforge.gg/cyberpunk-2077/map

Cyberpunk 2077 and the original game geometry belong to CD PROJEKT S.A. All rights reserved. AtlasForge is an independent map project. NetLore's projection uses a navy palette and omits gameplay markers. No affiliation or endorsement is implied, and no open-source license is claimed for the game artwork.
